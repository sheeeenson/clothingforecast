# Clothing Forecast

Погодное приложение, которое показывает не градусы, а готовый образ на улицу.

## Идея

Обычный прогноз говорит: `+12°C, ветер, облачно`.

Clothing Forecast отвечает на реальный вопрос пользователя: **что мне сегодня надеть?**

Приложение получает погоду по геолокации, учитывает терморегуляцию, стиль, пол и ситуацию, а затем генерирует визуальный образ одежды.

## Что умеет MVP

- Определяет город и текущую погоду через OpenWeather.
- Учитывает субъективное ощущение температуры: пользователь мёрзнет, чувствует нормально или быстро перегревается.
- Позволяет выбрать стиль: casual, business, evening, sporty, minimal, streetwear.
- Позволяет выбрать ситуацию: прогулка, офис, кафе, свидание, активный отдых.
- Генерирует реалистичный full-body outfit через Gemini image model.
- Если геолокация недоступна, использует Тбилиси как демо-город.

## Переменные окружения

Для работы нужны ключи:

```env
OPENWEATHER_API_KEY=your_openweather_key
GEMINI_API_KEY=your_gemini_key
```

Для обратной совместимости backend также читает старое имя `YOUR_VERCEL_API_KEY`, но лучше использовать `GEMINI_API_KEY`.

## Запуск на Vercel

1. Создай проект на Vercel из этого репозитория.
2. Добавь env-переменные:
   - `OPENWEATHER_API_KEY`
   - `GEMINI_API_KEY`
3. Задеплой проект.
4. Открой приложение и разреши геолокацию.

## Product vision

Дальше проект может вырасти в мини-платформу:

1. **AI looks** — генерация образов под погоду.
2. **User looks** — люди загружают свои реальные фото: как они оделись сегодня в конкретном городе и погоде.
3. **Brand looks** — бренды загружают свои подборки и вещи, которые нативно появляются в погодных рекомендациях.

Ключевая идея: не рекламировать одежду вне контекста, а показывать её в момент реальной потребности — когда человек собирается выйти на улицу.
